# 数据修复上机验证卡（2026-10-12）

配合 `tools/dbdiff/simulate_fix_effects.py` 的逻辑级复算使用：模拟器给出「服务器一定会算出什么」，
本卡是游戏内的对验步骤。进游戏先 `.gm on`。

## 测 1｜正义打击（51341-51345）→ 十字军打击给「狂热防御」

```
.gm on
.learn 10337        # 十字军打击 Rank 5（玩家真正能放的 2537 系）
.aura 51345         # 天赋「正义打击」Rank 5 的光环（等价点满）
# 拿武器打任意怪一下
```

* **通过**：自己身上出现 **狂热防御**（51336）buff（= 下一次成功格挡额外减 6% 伤害）。
* **A/B 对照**：`.unaura 51345` 后再打一次 → **不再出现**。
* **修好前**：永远不出现（掩码 0 → aura 109 的 `isAffectedOnSpell` 恒 false）。
* 判定只看法术家族与位图，不看职业，所以任何角色都能测。

## 测 2｜大地的召唤（58238/58239）→ 地盾层数

```
.learn 45525        # 大地之盾 Rank 1（施放版）
# ① 基线：对自己放「大地之盾」，看 buff 层数 = 3
.aura 58238         # 天赋「大地的召唤」Rank 1
# ② 再放一次 → 层数应变成 5
.unaura 58238
.aura 58239         # Rank 2 → 层数 7
```

* **通过**：层数 3 → **5**（Rank 1）/ **7**（Rank 2）—— `SpellAuras.cpp:6787`
  的 `ApplySpellMod(GetId(), SPELLMOD_CHARGES, m_procCharges)` 就是这条路径。
* 抗打断（aura 149）30% → **55% / 80%**（`Spell.cpp:7657`）由**同一条掩码**推动，
  游戏里没有可见数字，用「层数」当代理即可。
* **修好前**：层数恒为 3。

## 测 3｜古代仪祭图腾（物品 33091）→ 击倒 + 青蛙

```
.additem 33091      # 古代仪祭图腾（萨满圣物，需萨满角色；拖到圣物槽装备）
```

* **妖术** → **召出 3 只血口青蛙**（creature 872）攻击目标。
* **野性狼魂（45505）看不到变化是正常的**：它的触发 58246 是 DUMMY 空壳，内核没有实现。
* **修好前**：图腾猛击不击倒、妖术不召青蛙。

## 测 4｜宠物技能表（驯服后多出技能）

用猎人号（没有就先 `.learn 1515` 学会驯服野兽）。传送点与预期：

| 生物 | 传送命令 | 宠物表 | 驯服后应有 |
|---|---|---|---|
| 血爪鞭尾龙 3122 | `.go xyz 519.2 -4383.4 33.7 1` | 9500 | 野蛮撕扯（36536）|
| 暗礁蟹幼崽 2234 | `.go xyz 6991.7 394.9 -5.6 1` | 9509 | 泡沫屏障（36523）|
| 堕落的巨齿鳄鱼 3231 | `.go xyz -49.2 -3773.8 16.5 1` | 9495 | 死亡翻滚（36548）|
| 阿曼尼雄鹰 80815 | `.go xyz 2932.1 2524 139 1` | 9493 | 尖啸（24423）+ 爪击（16828）|

「已有列表补第二个技能」的例子：蜘蛛（**蛛网** 36533）、洛池鳄鱼（**死亡翻滚** 36548）、
铁鬃熊（**坚定怒吼** 36535）等。

* **通过**：驯服后宠物法术书里能看到上表技能。
* **服务端复核**（可选，直接看存档）：
  ```sql
  SELECT p.id, p.entry, ps.spell FROM tw_char.character_pet p
    LEFT JOIN tw_char.pet_spell ps ON ps.guid = p.id
   WHERE p.owner = (SELECT guid FROM tw_char.characters WHERE name = '角色名')
   ORDER BY p.id DESC LIMIT 10;
  ```
* **修好前**：9486-9518 段这些生物驯服后**一个技能都没有**。
